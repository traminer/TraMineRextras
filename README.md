# TraMineRextras

Collection of ancillary functions and utilities to be used in conjunction with the 'TraMineR' sequence Analysis package. Includes, among others, specific functions such as state survival plots, position-wise group-typical states, dynamic sequence indicators, and dissimilarities between event sequences. Also includes contributions by non-members of the TraMineR team such as methods for polyadic data and for the comparison of groups of sequences.


### Stable version

The stable version of TraMineRextras is available on the CRAN at https://cran.r-project.org/package=TraMineRextras.

It can be installed from within your R environment by entering command `pak::pak("TraMineRextras")`.

### Development version

The development version of TraMineRextras is available at https://github.com/traminer/TraMineRextras/

The last built `.tar.gz` source (which needs compilation) and `.zip` binary for Windows of the development version can be downloaded from folder `package` (https://github.com/traminer/TraMineRextras/tree/main/package). 


It can be installed from within your R environment by entering command `pak::pak("traminer/TraMineRextras")`.
